# 0010. 브라우저 테스트에서 표 상태 확인: 이름 상자 + window.__excel

- 상태: 채택
- 날짜: 2026-09-30
- 관련 Step: Step 2

## 배경
표는 Canvas로 그려서 Playwright가 화면 글자를 읽을 수 없다. 선택한 셀, 선택 범위, 스크롤 위치를 확인할 방법이 필요하다.

## 선택지
- A안 이름 상자 + 테스트용 전역: Excel처럼 표 위에 활성 셀 주소를 보여주는 이름 상자를 두고, 범위·보이는 범위는 `window`에 노출한 읽기 전용 객체로 확인 / 테스트용 코드가 앱에 조금 들어감
- B안 이름 상자만: 사용자 시점 그대로 / 범위를 이름 상자에 `A1:C3`처럼 보여야 해서 Excel(활성 셀만 표시)과 달라짐
- C안 테스트용 전역만: 화면 추가 없음 / 녹화 영상에서 어느 셀이 선택됐는지 글자로 안 보임

## 결정
A안.
- 이름 상자: `aria-label="이름 상자"`인 읽기 전용 입력칸. 활성 셀(`"B3"`)만 보여준다. (주소를 쳐서 이동하는 기능은 아직 없음)
- `window.__excel.state()`: `{ active: "B3", selection: "B3:D5", visible: "A1:T40" }`처럼 모두 `"A1"` 형태 글자로 돌려준다. 개발 서버(`NODE_ENV !== "production"`)에서만 만든다. 브라우저 테스트는 `next dev`로 돌기 때문에 항상 있다.

## 결과
- 테스트는 사용자가 보는 이름 상자를 먼저 확인하고, 화면에 안 보이는 상태만 `window.__excel`로 확인한다.
- 셀 좌표 클릭은 테스트가 칸 크기(`DEFAULT_LAYOUT`)를 알고 있어야 한다. 칸 크기를 바꾸면 `apps/web/e2e/excel.spec.ts`의 상수도 함께 바꾼다.
- 셀 값 확인이 필요해지면(Step 3) `state()`에 필드를 더한다.
