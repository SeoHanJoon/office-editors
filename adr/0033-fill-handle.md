# 0033. 채우기 핸들: 값을 이어가는 규칙

- 상태: 채택
- 날짜: 2026-10-01
- 관련 Step: Step 9

## 배경

Step 9에서 선택 범위 오른쪽 아래의 네모를 끌어 값을 이어 채운다. README는 "Excel과 같게"를 기준으로 삼았다.
숫자 1, 3처럼 간격이 일정하면 답이 하나지만, 간격이 들쭉날쭉하거나 종류가 섞인 범위, 이어갈 목록, 끄는 동안의 화면은 골라야 한다.

## 선택지

- 숫자 두 칸 이상
  - A안 Excel처럼 가장 잘 맞는 직선(최소제곱 추세): 1, 2, 4 → 5.33, 6.83 / 소수가 나와 처음엔 낯설다.
  - B안 마지막 두 칸의 차이: 1, 2, 4 → 6, 8 / Excel과 다르다.
- 종류가 섞인 범위 (예: `1`, `항목1`, `=A1`)
  - A안 Excel처럼 같은 종류가 붙은 묶음마다 따로 이어가고 순서를 되풀이: `text1, textA` → `text2, textA, text3, textA` / 규칙과 테스트가 늘어난다.
  - B안 한 줄이 모두 같은 종류일 때만 이어가고, 섞이면 복사를 되풀이 / Excel과 다르다.
- 이어갈 목록
  - A안 한국어와 영어 요일·월 / B안 한국어만 / C안 A안에 분기(1분기, Qtr1)까지
- 끄는 동안 보이는 것
  - A안 채울 범위에 회색 점선 테두리만 / B안 테두리와 마지막 칸 값 말풍선 (Excel과 같음, DOM과 위치 계산이 더 필요)

## 결정

모두 A안이다. (사용자 선택)

- 채우는 방향의 줄(아래로 채우면 열 하나)마다 따로 계산한다. 원래 칸들을 종류로 나누고, 같은 종류가 붙어 있으면 한 묶음이 된다.
  - 숫자: `parseNumber`로 읽히는 글자. 붙어 있는 숫자는 모두 한 묶음이다.
  - 끝에 숫자가 붙은 글자: 앞부분이 같으면 한 묶음이다. 숫자의 자릿수(`항목007` → `항목008`)를 지킨다.
  - 목록 글자: 같은 목록이면 한 묶음이다. 마지막 다음은 처음으로 돈다. (`12월` → `1월`)
  - 수식: 붙여넣기처럼 `$`가 없는 참조만 옮긴 만큼 따라간다. (ADR 0025, 0027)
  - 나머지 글자와 빈 칸: 그대로 복사한다.
- 묶음은 칸 위치(0, 1, 2…)에 대해 가장 잘 맞는 직선으로 다음 값을 정한다. 칸이 하나뿐인 묶음은 1씩 늘린다.
  - 예외: 원래 범위가 숫자 한 칸뿐이면 복사한다. (README 범위, Excel과 같음)
  - 글자의 숫자와 목록 순서는 정수로 반올림한다. 숫자는 `formatNumber`처럼 유효 숫자 15자리로 맞춘다.
- 원래 칸들의 순서를 되풀이하며 채운다. 위·왼쪽으로 채우면 같은 직선을 거꾸로 따라간다.
- 목록은 요일(`일`…`토`, `일요일`…`토요일`, `Sun`…`Sat`, `Sunday`…`Saturday`)과 월(`1월`…`12월`, `Jan`…`Dec`, `January`…`December`)이다. 영어는 대소문자 모양(`mon`, `Mon`, `MON`)을 따른다.
- 끄는 동안 채울 범위(줄일 때는 지울 범위)에 회색 점선 테두리를 그린다.

## 결과

- 간격이 일정한 숫자, 글자+숫자, 목록은 Excel과 같다. 종류가 섞인 범위도 같은 방식 하나로 처리한다.
- 채우기는 `SetCellsCommand` 하나라서 undo 한 번에 되돌아간다. (ADR 0015)
- Excel 동작 중 공식 문서로 확인하지 못한 것이 있다. 섞인 범위에서 숫자 한 칸이 1씩 느는 것, 위로 채울 때 글자의 숫자가 0 아래로 내려가는 경우 등은 경험적으로 알려진 동작을 따랐다. 실제 Excel에서 확인해야 한다.
- 이번에 넣지 않는 것: 사용자가 만드는 목록, 분기 목록, 날짜, 앞에 숫자가 붙은 글자(`1번`), 끌 때 값 말풍선, Ctrl을 누르고 끌어 복사·이어가기를 바꾸는 것, 채운 뒤 뜨는 "자동 채우기 옵션" 버튼
- 구현하며 정한 것 (Excel과 같게):
  - 규칙은 `fill.ts`의 순수 함수다. 줄 하나를 이어가는 `lineSeries`, 채우기 변경 `fillChanges`, 끈 곳으로 할 일을 정하는 `fillDrag`, 두 번 클릭 끝 행 `autoFillEnd`, Ctrl+D·R `copyFillChanges`, Ctrl+Enter `fillEntryChanges`
  - 대각선으로 끌면 더 멀리 나간 방향(같으면 세로)으로만 채운다. 범위 안으로 끌면 더 많이 줄어드는 축(같으면 행)의 뒤쪽 줄을 지운다. 끄는 중 Esc는 취소다.
  - 채운 뒤에는 늘어난 범위(줄였으면 남은 범위)를 고르고, 활성 셀은 그 안에 있으면 그대로 둔다.
  - 핸들은 7px 초록 네모에 흰 테두리다. 모서리에서 5px 안을 누르면 잡히고, 그 위에서는 마우스가 십자 모양이 된다.
  - 행·열 전체를 고르면 핸들을 그리지 않는다. Excel은 줄 전체를 옆으로 채울 수 있지만 넣지 않았다.
  - 두 번 클릭: 바로 왼쪽 열(바로 아래 칸이 비었으면 오른쪽 열)에 값이 이어진 곳까지 채운다. 채울 열에 이미 값이 있으면 그 앞에서 멈춘다. (경험적 동작)
  - Ctrl+D·Ctrl+R은 이어가지 않고 복사한다. 한 줄만 골랐으면 위·왼쪽 줄을 가져온다. Mac은 Cmd도 받고, 브라우저의 북마크·새로고침 단축키를 막는다.
  - Ctrl+Enter(Mac은 Cmd+Enter도)는 입력 중일 때만 동작한다. 수식은 칸마다 활성 셀에서 떨어진 만큼 상대 참조를 옮기고 선택은 그대로 둔다. Ctrl+Shift+Enter(배열 수식)는 막기만 한다.
- 측정 (Apple M1, `pnpm bench`):
  - 10만 행 성적표에서 핸들 두 번 클릭으로 I열 채우기 + 되돌리기: 숫자(1, 3) 0.38초, 수식(`=G2*2`) 0.58초. 목표는 없고 행 넣기(약 0.5초)와 비슷하다.
  - 한 화면 그리기는 핸들을 그려도 평균 0.44ms로 그대로다.
- 브라우저 테스트로 확인하지 못한 것: 실제 Ctrl/Cmd+R 새로고침이 막히는지. Playwright가 보낸 키는 브라우저 단축키를 거치지 않으므로 사람이 확인해야 한다.
