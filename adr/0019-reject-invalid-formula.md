# 0019. 문법이 틀린 수식은 확정하지 않는다

- 상태: 채택
- 날짜: 2026-09-30
- 관련 Step: Step 4

## 배경
사용자가 `=1+`, `=SUM(A1`처럼 문법이 틀린 수식을 치고 Enter를 누를 때 어떻게 할지 정해야 한다.

## 선택지
- A안 저장하고 셀에 에러 표시: 알림 UI가 필요 없음 / Excel은 확정 자체를 막음
- B안 Excel처럼 확정 거부 + 알림: Excel과 같음 / 알림 UI와 브라우저 테스트가 더 필요

## 결정
B안.
- Enter·Tab·방향키·다른 셀 클릭으로 확정할 때 수식 문법을 검사한다. 틀렸으면 확정하지 않고, 선택도 옮기지 않고, 입력을 이어가게 한다.
- 입력창 바로 아래에 `role="alert"` 알림("수식에 문제가 있습니다. 닫는 괄호())가 없습니다.")을 띄우고 커서를 문제 위치에 둔다.
- 글자를 고치면 알림이 사라진다. Esc는 입력과 알림을 함께 취소한다.
- 아는 함수의 인자 개수가 틀린 것(`=SUM()`)도 Excel처럼 문법 오류로 막는다.

## 결과
- 화면에서는 틀린 수식이 시트에 들어가지 않는다.
- 처음 데이터나 코드로 넣은 틀린 수식은 엔진이 멈추지 않고 `#NAME?`으로 보여준다.
- Excel은 대화상자를 띄우고 괄호를 자동으로 고쳐주기도 하지만, 여기서는 알림만 띄운다.
