# 0018. 다시 계산: 의존성 그래프와 순환 참조

- 상태: 채택
- 날짜: 2026-09-30
- 관련 Step: Step 4

## 배경
셀 값이 바뀌면 그 셀을 참조하는 수식을 다시 계산해야 한다. Step 5 목표는 "연결된 셀 1만 개 다시 계산 0.05초", "큰 `SUM`이 있는 시트에서 셀 하나 수정 0.016초"다.
수식끼리 서로를 참조하는 순환 참조(`A1=B1`, `B1=A1`)도 잡아서 보여줘야 한다.

## 선택지
- 다시 계산 방식
  - A안 의존성 그래프: "어떤 셀이 어떤 셀을 참조하는지" 지도를 두고 바뀐 셀에 이어진 수식만 순서대로 계산 / 코드가 늘어남
  - B안 매번 전체 계산: 가장 단순 / Step 5에서 결국 다시 만들어야 함
- 순환 참조 표시
  - A안 Excel처럼 0 + 경고 표시줄: Excel과 같음 / 경고 UI가 필요, HyperFormula와 비교 불가
  - B안 에러 값 표시: 셀만 봐도 알 수 있음 / Excel과 다름
- 순환 에러 이름: `#CYCLE!`(HyperFormula와 같아 정답 비교 가능, Excel에 없음) / `#REF!`(Excel에 있는 이름, Step 6의 삭제된 참조와 구분 안 됨)

## 결정
- 다시 계산은 A안.
  - 수식 셀마다 참조하는 셀 목록과 범위 목록을 둔다. 거꾸로 "셀 → 그 셀을 참조하는 수식" Map도 둔다.
  - 범위(`A1:A10000`)는 셀로 풀지 않고 범위 그대로 둔다. 바뀐 셀이 범위 안에 있는지는 범위를 가진 수식을 하나씩 확인한다.
  - 바뀐 셀에서 참조를 따라가며 다시 계산할 셀을 모으고, 참조되는 쪽부터 계산한다. (위상 정렬: 아직 계산 안 된 셀을 참조하지 않는 셀부터)
- 순환 참조는 B안 + `#CYCLE!`.
  - 순서가 안 정해지고 남은 셀 중 서로를 참조하는 묶음(또는 자기 자신 참조)만 `#CYCLE!`로 둔다. (Tarjan 강한 연결 요소)
  - 순환을 참조만 하는 셀은 보통 수식처럼 계산해 에러를 받는다. (`=A1+1` → `#CYCLE!`, `=COUNT(A1)` → 0)
- 그래프 탐색과 순환 찾기는 재귀 없이 쓴다. 1만 개가 이어진 수식에서도 스택이 넘치지 않는다. (테스트 있음)

## 결과
- 셀 하나를 바꾸면 그 셀에 이어진 수식만 다시 계산한다. `engine.onChange`로 다시 계산된 셀 목록을 알 수 있어 테스트로 확인한다.
- 범위 수식이 아주 많으면(수만 개) 셀 하나 바꿀 때마다 모든 범위를 훑는다. Step 5에서 측정해 느리면 범위 색인을 더한다.
- 범위 값을 읽을 때 범위 칸을 모두 훑는다. 시트 크기로 잘라내지만, 값이 드문 큰 범위는 Step 5에서 값이 있는 셀만 훑도록 바꿀 수 있다.
- Excel과 다른 점: Excel은 순환 셀을 0으로 보여주고 경고를 띄우지만 여기서는 `#CYCLE!`을 보여준다.
