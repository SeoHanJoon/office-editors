# 0004. PR 영상은 GitHub Actions에서 녹화해 아티팩트로 올린다

- 상태: 폐기 (→ 0005)
- 날짜: 2026-09-30
- 관련 Step: Step 0

## 배경
PR마다 브라우저 테스트 영상을 붙이기로 했지만, GitHub PR 본문에 영상을 올리는 공개 API가 없다.
`gh`로 PR을 만들어도 영상은 사람이 웹에서 직접 드래그해야 했다.

## 선택지
- A안 webm → GIF로 바꿔 전용 브랜치에 올리고 본문에 넣기: PR 본문에서 바로 재생 / `ffmpeg` 설치 필요, 화질 저하
- B안 webm을 전용 브랜치에 올리고 링크: 원본 그대로 / 본문에서 재생 안 됨
- C안 GitHub Actions에서 녹화 후 아티팩트로 올리기: 내 컴퓨터 없이 PR마다 자동 녹화 / zip을 받아 풀어야 보이고, 90일 뒤 삭제

## 결정
C안. 녹화를 사람이 챙기지 않아도 되고, 저장소에 영상 파일이 쌓이지 않는다.
- `.github/workflows/e2e-record.yml`이 PR을 열거나 push할 때마다 `pnpm e2e:record`를 실행한다.
- 영상은 `recordings-pr-<번호>` 아티팩트로 올리고, PR에 링크 댓글을 하나 단다. 다시 녹화하면 같은 댓글을 고친다.
- 테스트가 실패해도 영상은 올린다.

## 결과
- 로컬 `pnpm e2e:record`는 그대로 쓸 수 있지만, PR에 영상을 드래그할 필요는 없어졌다.
- 영상을 보려면 zip을 받아야 하고, 아티팩트는 90일 뒤 사라진다. 오래 남길 영상은 따로 옮겨야 한다.
- PR마다 CI 시간(브라우저 설치 포함 몇 분)이 든다.
