# Excel 함수 추가: $ARGUMENTS

## 0. 먼저 확인

- 수식 엔진 구조는 Step 3의 ADR(`adr/`)을 따른다. 기존 함수 1~2개의 구현과 테스트를 읽고 같은 방식으로 만든다.
- 수식 엔진이 아직 없으면 멈추고 사용자에게 알린다.

## 1. Excel 동작 정리 (구현 전에)

함수마다 아래를 짧게 정리해서 사용자에게 보여준다. 모르거나 헷갈리면 Microsoft 공식 문서를 확인한다.

- 인자: 개수, 선택 인자, 기본값
- 빈 셀, 텍스트, 논리값(TRUE/FALSE)이 들어오면 어떻게 되나
  - 예: `SUM`은 범위 안의 텍스트를 무시하지만 `=SUM("a")`처럼 직접 넣은 텍스트는 `#VALUE!`
- 에러 입력(`#DIV/0!` 등)이 들어오면 그대로 전파하나
- 어떤 경우에 어떤 에러를 내나 (`#VALUE!`, `#N/A`, `#NUM!`, `#REF!`)

## 2. 구현

- 기존 함수와 같은 등록 방식과 인자 처리 헬퍼를 쓴다. 새 헬퍼가 필요하면 기존 함수에도 쓸 수 있게 만든다.
- 외부 수식 라이브러리를 쓰지 않는다. (HyperFormula는 테스트 전용)

## 3. 테스트

### 단위 테스트 (함수 파일 옆 `*.test.ts`)

함수마다 최소한 아래를 넣는다.

- 기본 동작
- 빈 셀 / 텍스트 / 논리값
- 에러 입력 전파
- 인자 개수 틀림
- 범위 인자가 있으면: 1칸 범위, 여러 행·열 범위

### HyperFormula 정답 비교 테스트

- 같은 셀 값과 수식을 HyperFormula에도 넣고 결과가 같은지 확인한다.
- 결과가 다르면 Excel 기준으로 누가 맞는지 확인한다.
  - HyperFormula가 Excel과 다르면 그 케이스는 비교에서 빼고, 이유를 테스트 주석에 적는다.

## 4. 완료

- `pnpm test`와 `pnpm typecheck`를 실행하고 결과를 보고한다.
- 사용자에게 보고할 때 Excel과 다르게 동작하는 부분이 있으면 따로 적는다.
