# 테스트 규칙

- 단위 테스트(Vitest)는 코드 파일 옆에 `<이름>.test.ts`로 둔다.
- 테스트 이름은 무엇을 확인하는지 한국어로 쓴다. (예: `빈 셀은 0으로 더한다`)
- 테스트를 통과시키려고 기대값을 바꾸지 않는다. 기대값이 틀렸다고 판단되면 근거와 함께 사용자에게 알린다.
- 브라우저 테스트(Playwright)
  - 사용자가 실제로 하는 동작(클릭, 키보드, 붙여넣기, 한글 입력)으로 조작한다.
  - Excel 표는 Canvas라서 화면 글자를 읽지 않는다. 결과는 앱이 노출한 내부 데이터로 확인한다.
  - `pnpm e2e:record`로 실행하면 영상이 `recordings/`에 저장된다. 영상은 PR 확인용이므로 사람이 보고 흐름을 이해할 수 있게 동작 사이에 너무 빠르게 넘어가지 않는다.
  - `recordings/`는 커밋하지 않는다.
